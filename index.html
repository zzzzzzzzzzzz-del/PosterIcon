▶️ Применить тему

Как это работает

  1. Установи один раз универсальный шорткат ApplyTheme (инструкция ниже).
  2. Открой эту страницу на iPhone в Safari.
  3. Нажми «Применить тему» — откроется «Команды» с готовым сценарием.
  4. Для каждой иконки в шорткате выбери «Добавить на экран "Домой"».

⚠️ iOS не даёт автоматически создавать ярлыки — только вручную. Зато никакого JSON и никакого сервера не нужно: все данные вшиты в эту страницу.

🛠️ Создай шорткат ApplyTheme (один раз)

  1. Открой «Команды» → + → назови ApplyTheme.
  2. В настройках шортката (ⓘ) включи «Принимать URL» и «Принимать текст».
  3. Добавь действие «Получить текст» → вход: Краткий ввод.
  4. Добавь действие «Получить словарь из входных данных».
  5. Добавь действие «Получить значение по ключу» → ключ: icons.
  6. Добавь действие «Повторить для каждого».
  7. Внутри цикла — «Открыть приложение» → выбери любое (Safari).
  8. Вернись к параметру приложения и замени на Переменную → Элемент повтора → app.
