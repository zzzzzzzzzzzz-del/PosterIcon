## ✨ Что это

**PosterIcon** — это веб-сайт и набор JSON-конфигураций, который позволяет
применять кастомные иконки и обои на iPhone **без джейлбрейка**. Работает
через штатное приложение «Команды» (Shortcuts) на iOS 18 и новее.

Проект состоит из трёх частей:

1. **Каталог тем** — `index.html` с превью иконок в двух вкладках (Part 1 / Part 2).
2. **Универсальный шорткат** `ApplyTheme` — читает JSON темы и создаёт ярлыки.
3. **JSON-файлы тем** — `ios26_part1.json` (28 иконок) и `ios26_part2.json` (21 иконка).
